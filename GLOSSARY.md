# Astronom

A platform where people describe a job, get a team of AI agents built for it, and run those agents under permissions they control.

## Language

### Building agents

**Agent builder**:
The conversation, by text or voice, that turns what a person wants automated into an agent draft they can create.
_Avoid_: Builder chat, composer, wizard

**Astro**:
The agent builder's voice: a spoken assistant that interviews the person until the job is clear, then drafts the agent.
_Avoid_: Jarvis, voice builder, assistant

**Agent draft**:
A proposed agent and its workers, not yet created, that the person reviews and changes before creating it.
_Avoid_: Proposal, spec, plan

**Workflow video**:
A screen recording of a person doing a job by hand, given to the agent builder as the description of what to automate.
_Avoid_: Demo video, tutorial

### Voice

**Voice agent**:
An agent that takes calls and acts on them by itself, such as an after-hours receptionist that checks a calendar and books appointments.
_Avoid_: Phone bot, IVR, call agent

**Voice line**:
A page that stands in for a voice agent's phone number: opening it starts a call with that agent.
_Avoid_: Phone number, deployment page, demo tab
